# Project Setup Guide

新規プロジェクト立ち上げ手順書集。Claude Code on the Webでの操作を前提とし、コマンドで完結できる手順をまとめています。

## ガイド一覧

| ガイド | 説明 |
|--------|------|
| [React + Vite + S3 + CloudFront](guides/react-vite-s3-cloudfront.md) | React/TypeScript/Vite + AWS S3/CloudFront + Claude Code Action |

## 使い方

1. 作成したいプロジェクトの構成に合ったガイドを選択
2. 手順に従ってセットアップを実行
3. 必要に応じてプロジェクト固有の設定を追加

## 共通の前提条件

- GitHub アカウント
- AWS アカウント（S3/CloudFront を使用する場合）
- Anthropic API キー（Claude Code Action を使用する場合）
